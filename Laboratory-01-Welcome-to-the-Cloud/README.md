# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This activity introduced me to Linux and the basic tasks used in a cloud environment. I used KillerCoda to practice Linux commands and GitHub to organize and store my portfolio.

## Objectives

- Access Linux through KillerCoda.
- Learn basic Linux navigation and commands.
- Check operating system, memory, and storage information.
- Create and organize folders and files.
- Set up a GitHub repository.
- Use Markdown for documentation.

## Activities Performed

- Accessed the KillerCoda terminal.
- Created a new Linux user and gave it sudo access.
- Checked my username, working directory, and hostname.
- Gathered system information.
- Created and organized folders and Markdown files.
- Prepared my laboratory portfolio for GitHub.

## Linux Commands Used

- adduser

- su

- hostname

- uname
- lscpu
- free

- mkdir
- nano
- cp

- git

## Skills Learned

I learned how to work with a Linux terminal, manage a user account, check system information, organize files, create Markdown documentation, and prepare a portfolio using GitHub.
