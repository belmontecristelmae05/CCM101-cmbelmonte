# Cloud Infrastructure Components

## Compute Resources

### Purpose

Compute resources are the processing capabilities available to a cloud server. These resources allow the system to execute commands, applications, and different workloads.

### Why It Is Important

Compute resources are necessary because they provide the processing power and memory required by applications and system operations.

### Relation to the Linux Environment Provided by KillerCoda

I examined the CPU model, CPU cores, and RAM in the KillerCoda Linux environment. The results showed the amount of computing capacity available for running commands and performing server tasks.

## Storage Resources

### Purpose

Storage resources provide space for keeping system files, applications, configurations, and other data.

### Why It Is Important

Storage is essential because applications and operating systems need a place to save and retrieve information.

### Relation to the Linux Environment Provided by KillerCoda

I used `df -h` to examine the available disk space and `findmnt` to check the mounted file systems. These commands helped me understand how storage is arranged in the Linux environment.

## Networking Resources

### Purpose

Networking resources provide communication between servers, users, devices, and other cloud services.

### Why It Is Important

Networking allows cloud resources to exchange information and makes applications and services accessible through connected systems.

### Relation to the Linux Environment Provided by KillerCoda

I used `hostname -I` to identify the IP addresses of the KillerCoda server. This helped me understand how the Linux environment is identified within its network.

## Operating System

### Purpose

The operating system controls the server's hardware and software resources and provides an environment for running applications and commands.

### Why It Is Important

It is important because it manages the available resources and allows users and applications to interact with the server.

### Relation to the Linux Environment Provided by KillerCoda

The KillerCoda Playground provided an Ubuntu Linux environment. I used its terminal to investigate the server's hardware, storage, network information, and other system details.
