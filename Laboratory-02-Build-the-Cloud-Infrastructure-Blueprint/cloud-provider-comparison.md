# Cloud Provider Comparison

## Infrastructure Service Comparison

| Infrastructure Component       | AWS        | Microsoft Azure        | Google Cloud Platform       |
| ------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                        | Amazon EC2 | Azure Virtual Machines | Compute Engine              |
| Storage                        | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                     | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM    | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

I would select **AWS** because it provides a wide selection of cloud services for different types of workloads. It has services for computing, storage, databases, networking, security, and many other cloud requirements. This gives organizations several choices when creating their infrastructure.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it is closely integrated with Microsoft's products and technologies. An organization that already depends on Microsoft tools may find it easier to connect its existing systems with Azure services.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

I would choose **Google Cloud Platform** because of its strong focus on Artificial Intelligence and Machine Learning. It also provides Kubernetes-related services that can help organizations deploy and manage containerized applications.

### 4. What similarities did you observe among the three cloud providers?

The three providers offer many of the same basic categories of cloud services. **AWS, Microsoft Azure, and Google Cloud Platform** all provide computing, storage, networking, and identity management solutions. Their service names and features may differ, but they are all designed to support cloud applications and infrastructure.
