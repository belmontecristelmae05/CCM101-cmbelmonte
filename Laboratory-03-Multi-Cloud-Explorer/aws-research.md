# Amazon Web Services (AWS) 

> Introduced in 2006, Amazon Web Services (AWS) is a cloud computing platform offering scalable computing power, storage solutions, and networking capabilities.

## Global Infrastructure
AWS spans a worldwide network of isolated **Regions** and **Availability Zones** to deliver continuous uptime and built-in fault tolerance.

## Management Console
Administrators configure and monitor resources through the web-based **AWS Management Console**.

## Core Services

| Service | Category | Function |
| :--- | :--- | :--- |
| **EC2** | Compute | Virtual server instances |
| **S3** | Storage | Durable object storage |
| **RDS** | Database | Managed relational databases |
| **VPC** | Networking | Isolated virtual cloud networks |

## Key Advantages
- Extensive directory of cloud services
- Highly scalable and elastic architecture
- Resilient global network footprint

## Common Use Cases
* **Web Hosting:** Deploying scalable websites and web apps
* **App Development:** Building and running software backends
* **Data Storage:** Storing, archiving, and backing up data
