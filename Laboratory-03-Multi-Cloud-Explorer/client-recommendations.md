# Cloud Platform Recommendation Challenge 

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended for the startup because it offers a wide range of services and flexible cloud resources. The company can start with a small amount of resources and increase them as the mobile app gains more users. AWS also provides services that can support fast application development and growth.

### Recommended Services

- **Amazon EC2** – Provides virtual servers for running the mobile application's backend.
- **Amazon S3** – Stores images, files, backups, and other application data.
- **Amazon RDS** – Provides a managed relational database for storing application information.


---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies, making it easier to migrate existing services to the cloud. The university can continue using familiar Microsoft-based tools while improving its cloud infrastructure.

### Recommended Services

- **Azure Virtual Machines** – Can host Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides identity and access management for users and applications.
- **Azure SQL Database** – Provides a managed SQL database service for university applications and systems.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is recommended for the AI research company because it provides strong services for artificial intelligence, machine learning, and high-performance workloads. It also provides tools for developing and deploying AI applications. GCP's support for Kubernetes makes it useful for running containerized AI workloads.

### Recommended Services

- **Compute Engine** – Provides virtual machines for high-performance computing workloads.
- **Vertex AI** – Provides tools for developing, training, and deploying machine learning models.
- **Google Kubernetes Engine (GKE)** – Provides a managed Kubernetes environment for deploying containerized applications.


---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it provides scalable and reliable cloud infrastructure for applications serving customers around the world. The company can use AWS services to handle changing traffic and maintain application availability. AWS also provides infrastructure in multiple regions to support global operations.

### Recommended Services

- **Amazon EC2** – Runs the company's web applications and backend services.
- **Amazon S3** – Stores product images, files, backups, and other data.
- **Elastic Load Balancing (ELB)** – Distributes incoming traffic across multiple resources to improve availability and performance.

# Multi-Cloud Decision Matrix

| Business Scenario | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Flexible and scalable for growing businesses. |
| Enterprise Organization | AWS | Offers a wide range of enterprise services. |
| Microsoft Environment | Microsoft Azure | Strong integration with Microsoft technologies. |
| AI / Machine Learning | GCP | Strong AI and machine learning services. |
| Kubernetes Deployment | GCP | Provides strong Kubernetes support through GKE. |
| Global Web Application | AWS | Reliable and scalable global infrastructure. |
