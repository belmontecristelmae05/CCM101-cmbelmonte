## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

- Amazon Web Services offers the broadest range of services because it has the most complete and mature cloud ecosystem. It provides solutions for computing, storage, databases, networking, and more. This makes it suitable for almost any type of application or business.

### 2. Which provider best integrates with Microsoft technologies?

- Microsoft Azure integrates best with Microsoft technologies since it works seamlessly with tools like Windows Server and Microsoft 365. It allows organizations to easily extend their existing systems to the cloud. This makes management and user access more efficient.

### 3. Which provider is strongest in AI and Kubernetes?

- Google Cloud Platform is strongest in AI and Kubernetes due to its advanced machine learning tools and data analytics services. It also has native support for Kubernetes, which was originally developed by Google. This makes it ideal for scalable and data-driven applications.
  
### 4. Which cloud platform would you personally choose and why?

- I would choose Amazon Web Services because it is flexible and widely used across industries. It offers many services that can support both small and large projects. It is also reliable and has strong community support.
