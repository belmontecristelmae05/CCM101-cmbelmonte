# The Google Cloud Platform (GCP) Research

## Overview
in my research, the GCP is a cloud platform by Google launched in 2008, known for AI and data analytics.

## Global Infrastructure
GCP uses Google's global network with regions and zones.

## Cloud Management Console
Google Cloud Console is used to manage resources.

## Core Services
- Compute Engine
- Cloud Storage
- BigQuery
- VPC

## Advantages
- Strong AI/ML tools
- Fast data analytics
- Kubernetes support
