# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud storage and object storage. I compared different types of storage and deployed MinIO using Docker. I also accessed the MinIO web console, created a bucket, and uploaded an image to test the object storage service.

## Objectives

- Understand the differences between block, file, and object storage.
- Deploy MinIO using Docker.
- Access the MinIO web console through a specific port.
- Create an object storage bucket.
- Upload an image to the bucket.
- Document the deployment process using Markdown.

## Tools Used

- KillerCoda
- Ubuntu Linux
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

I learned how to use basic Linux command-line commands, work with Docker containers, deploy MinIO using Docker, and access a web service through a specific port. I also learned how to create an object storage bucket, upload an image to MinIO, and document the deployment process using Markdown in a GitHub repository.
