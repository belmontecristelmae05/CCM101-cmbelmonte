# Laboratory Activity 7: The Cloud Operations Engineer

## Mission Overview

In this laboratory activity, I performed the role of a Cloud Operations Engineer at CloudNova Technologies. I checked the health of a Linux server, deployed an Nginx web server using Docker, generated web traffic, examined application logs, and monitored container performance using Docker metrics.

I used the KillerCoda Playground to execute Linux and Docker commands. I also documented the results and prepared screenshots as evidence of the completed activities.

## Objectives

- Monitor host CPU, memory, and disk storage.
- Use Linux commands to check system resources.
- Deploy an Nginx web server using Docker.
- Generate HTTP requests using the curl command.
- Examine application logs using docker logs.
- Monitor container CPU, memory, and network usage using docker stats.
- Document technical results using Markdown.
- Maintain a well-organized GitHub repository.

## Monitoring Commands Executed

### 1. Check Memory Usage

Command:

    free -h

This command displays the total, used, and available memory of the host server.

### 2. Check Disk Storage

Command:

    df -h /

This command displays the total, used, and available storage space of the root file system.

### 3. Monitor Running Processes

Command:

    top

This command displays active processes, CPU utilization, memory usage, and system load. Press q to exit.

### 4. Deploy the Nginx Container

Command:

    docker run -d --name clientwebsite -p 8080:80 nginx

This command deploys an Nginx web server in the background and maps port 8080 on the host to port 80 inside the container.

### 5. Generate Web Traffic

Commands:

    curl http://localhost:8080
    curl http://localhost:8080
    curl http://localhost:8080

These commands simulate three visits to the website.

### 6. Generate an HTTP Error

Command:

    curl http://localhost:8080/hidden-admin-page

This command requests a nonexistent page and should return an HTTP 404 response.

### 7. View Application Logs

Command:

    docker logs clientwebsite

This command displays the logs generated by the Nginx container, including HTTP requests and response status codes.

### 8. Monitor Container Metrics

Command:

    docker stats clientwebsite

This command displays the container's real-time CPU usage, memory consumption, network I/O, and other resource metrics. Press Ctrl+C to exit.
