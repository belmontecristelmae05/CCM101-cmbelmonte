# Mission Reflection

Completing this laboratory activity helped me understand the importance of protecting a server using a host-based firewall. A host-based firewall controls incoming and outgoing network traffic directly on the server. Even if an attacker gets past the main network security defenses, the firewall can still block unauthorized connections based on its configured rules. This provides another layer of protection for the server.

I also learned that managing open network ports is important for reducing a server's attack surface. Every open port may provide an entry point that attackers can target. Closing unused ports and allowing only the necessary connections can help reduce security risks. For this reason, server administrators should regularly check their firewall rules and make sure that only required ports are accessible.

In an enterprise environment, leaving a database port such as MySQL port 3306 open to the public internet can be dangerous. Attackers may attempt to guess passwords or exploit security weaknesses to access the database. If they succeed, important company information could be stolen, changed, or deleted. Database connections should be restricted to trusted servers and authorized users to protect sensitive information.

This mission changed my perspective on how easily a server can be compromised. Before completing the activity, I focused more on making the web server work properly. Now, I understand that server security is also important and that even a working server can be vulnerable if its ports and firewall rules are not configured correctly. I learned that using a firewall and allowing only necessary traffic are important steps in protecting a server.
