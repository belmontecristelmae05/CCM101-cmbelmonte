# Security Audit Report


## The Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their assigned tasks. It is important for cloud user accounts because it limits access to sensitive files, services, and resources. If an account is compromised, the attacker will have fewer permissions to misuse.

## Attack Surface

The attack surface of a virtual machine refers to all the possible points where an attacker could try to gain access to the system. These include open ports, running services, applications, and remote access connections. Reducing unnecessary services and closing unused ports can help minimize security risks.

## Default Deny Policy

A default deny policy blocks all incoming traffic unless it is specifically allowed by a firewall rule. It is safer than trying to block individual hackers because it prevents unknown and unauthorized connections from accessing the system by default. This approach reduces the risk of attacks by allowing only the traffic that is necessary.
